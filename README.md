# 🌸 星绒岛奇遇记 Starwhim Island

面向约 5–9 岁儿童的原创梦幻童话网页游戏。**无需登录、无广告、无内购。**

## ✨ 当前版本：v1.2 丁一一专属卡通语音版
- 6 座探索岛屿、8 位可结识精灵、11 段主线、8 种可重复小游戏
- 花园、家园装饰、换装、星愿邮局、礼物和友情故事、本机自动存档
- **中文语音导航：** 开场介绍、角色对话、任务、地图和菜单、小游戏规则及通关提示
- **随时重听：** 主界面与对话、小游戏弹窗里的 🔊 按钮
- **声音设置：** 家长设置页中的「试听中文语音」、音效、背景音乐与语音独立开关
- **不识字友好：** 图标优先、语音引导、失败无惩罚；建议家长第一次陪同体验

## 🧸 丁一一的卡通语音\n- 主人公与欢迎词使用 **「小冒险家丁一一小朋友」**，任务和祝贺会亲切地称呼丁一一。\n- 语音有泡泡萌萌音、月芽温柔音和栗栗活力音三档，优先选用设备中文女声音色并微调语速、音高。\n- 手机端取消了首次朗读前的无条件语音取消操作；朗读对象会保持引用，支持用户主动点击唤醒朗读。\n- 家长设置新增 **「🎵 试听叮咚音效」**，帮助区分媒体音量问题与手机中文语音引擎问题。\n- **重要限制：**卡通音色通过设备 Web Speech 语音合成调节，无法在所有手机上保证相同自然度；目前不包含真人或神经网络配音音频，也无法保证不支持中文朗读的浏览器自动发声。\n\n## 🎮 运行与部署
这个仓库的根目录 **`index.html`** 就是完整的单文件游戏。
- 支持直接用现代浏览器打开 HTML；不依赖后端、npm、CDN 或远程接口
- 可以连接到支持「从 GitHub 导入」的静态网站托管平台，发布目录为仓库根目录，入口为 `index.html`
- **不要把 GitHub 仓库页面误当成游戏网页。** 仓库用于保存代码；需经过静态网站托管才有可直接游玩的 HTTPS 地址
- 目前旧预览站 `https://starwhim-island.vercel.app` 仍可能无法在中国大陆访问，**国内站点尚未验证**
- 网站域名变化不会自动迁移浏览器本地存档；请在原站家长设置中先导出备份
- 纯本地 `file://` 模式可玩游戏，但不同浏览器对本地存档的支持有所不同；长期建议使用稳定 HTTPS 域名

## 🔊 第一次播放声音
1. 点击「🔊 听泡泡介绍小岛」或「进入梦幻小岛」，触发浏览器的音频授权
2. 若没听到人声，打开右上角齿轮，在家长设置中打开「中文语音朗读」，点击「🔊 试听中文语音」
3. 调大媒体音量，关闭手机静音模式；如依然没有声音，请检查系统是否安装/启用了普通话语音合成引擎，或更换浏览器
4. 不同手机浏览器的中文语音引擎支持情况不同，**目前没有随游戏捆绑真人音频**；视觉字幕仍始终存在

## 🧒 隐私和儿童安全
无陌生人聊天、无个人信息采集、无广告和内购。存档仅在当前设备的浏览器本地存储，清理浏览器数据可能丢失，请家长定期备份。没有账号和跨设备云同步。
