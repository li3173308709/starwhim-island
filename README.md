# 🌸 星绒岛奇遇记 · 送给丁一一小朋友

**v1.4：统一采用 Voxy「语界」中的「活泼女孩 2.0」声音。**

游戏包含六个岛屿、八位精灵、11段主线、八种小游戏、花园和家园、换装、星愿邮局等。

## 🎙 声音现状

- 已取消泡泡「云小朵」和旁白「云小团」的双音色方案；泡泡、旁白、小游戏和任务一律配置为 **语界「活泼女孩 2.0」**。
- 游戏代码已实现 MP3 优先播放、手机触控播放、重听、缺失音频时提示。
- **目前真正由语界导出的 MP3 文件是 0 / 79 条。** 没有接入语界合成账户，因此当前有声内容仍由设备内置中文朗读临时替代，**并非实际「活泼女孩 2.0」声音**。
- 语界试听页面：https://voxyai.cn/examples.html
- 79句详细台词与一键导入脚本见本对话提供的完整 v1.4 工程 ZIP。
- 在语界自行合成合法可用的 MP3 后，依照 `voxy-配音台词清单.csv` 命名，将文件放入 `assets/voice/voxy_inbox/`，运行 `scripts/import_voxy_voice_oneclick.py` 生成离线语音包。浏览器端不存储任何语界令牌。

## 🎮 使用

GitHub 根目录的 `index.html` 是完整单文件游戏的网页版源代码。连接适合中国大陆的静态站点托管后，通过 HTTPS 访问即可游玩。GitHub 仓库页面本身不是游戏网址。

浏览器的本地存档与域名绑定，更换域名请先在旧页面的家长设置里导出存档。
