# 🌸 星绒岛奇遇记 · 送给丁一一小朋友

## v1.6 — 已内置真实语界「活泼女孩」欢迎语 + 手机端同版布局

- 完整单文件游戏：仓库根目录 `index.html`，可直接静态部署或离线打开。
- **已真正嵌入用户提供的 11.616 秒 MP3 欢迎语**（独立试听、开始游戏欢迎、游戏右上角 🔊 重播，均播放相同真实录音）。
- MP3 内容为：「丁一一小朋友，你好呀！我是泡泡。欢迎来到星绒岛！瞧，云朵像棉花糖一样软软的。我们一起去寻找亮晶晶的小星星，好不好呀？」
- 使用浏览器原生 `HTMLAudioElement` 播放嵌入的 MP3，无需调用手机系统的中文机械朗读服务、外部 CDN 或付费接口。遵守手机浏览器的用户手势启动限制，需要主动点击声音按钮。
- 所有游戏录音**只接受相同“活泼女孩”来源的正式 MP3**；尚无录音的任务、剧情、小游戏不会悄悄使用另一种机械音。它们保留文字和玩法，不等于已全部配音。
- 已整理 79 句优先配音清单，**目前实际音频覆盖 1/79**。其他句子需在语界以相同音色合成 MP3 后导入；不能用一段录音凭空读出不同内容。
- 手机版和电脑版同一套顶部导航、底部六入口、三列地图卡片、对话框等布局。针对 320/360/390px 手机屏、桌面及横屏做了页面测试。
- 自动化测试确认手机尺寸模拟浏览器中 MP3 `play()` 成功并且播放进度前进；不同品牌真实手机的发声仍需现场试听。
- 存档仅在浏览器本地，换域名之前请导出存档。
